# Documentation

Esta carpeta contiene los documentos entregables generados para ViajaPro.

## Uso

- `.docx`: documentos editables entregables.
- `.pdf`: versiones finales para distribución.
- Otros archivos de soporte solo cuando sean necesarios para reproducir o actualizar un entregable.

Los documentos de especificación, arquitectura, decisiones y conocimiento interno del proyecto permanecen en las carpetas estructurales de `docs/`.

## Regla

Esta carpeta no sustituye la documentación fuente del repositorio. Un entregable debe poder rastrearse hasta los documentos fuente que lo sustentan.
